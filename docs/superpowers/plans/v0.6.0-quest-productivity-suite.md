### B. `src/core/deadlineScheduler.ts` (New Module — Issue #11)

Create a pure, zero-dependency scheduler evaluated inside the existing 5-second `setupWellnessCoachTicker` in `src/main/index.ts`:

```typescript
import { ReminderState, DeadlineAlertStage } from './reminderStore';

export interface DeadlineAlertEvent {
  questId: string;
  questText: string;
  stage: DeadlineAlertStage;
  message: string;
  soundEvent: 'wellness-reminder';
}

export interface DeadlineEvaluationResult {
  state: ReminderState;
  alerts: DeadlineAlertEvent[];
}

export function evaluateDeadlineAlerts(
  state: ReminderState,
  now: Date = new Date(),
  eveningHour = 19
): DeadlineEvaluationResult;
```

#### Rules for `evaluateDeadlineAlerts`:

- Only inspect uncompleted items (`!item.completed`) that have a valid `item.dueDate` (`YYYY-MM-DD`).
- Compute `diffDays = daysBetweenYMD(todayYMD, item.dueDate)` where `todayYMD = formatLocalDateYMD(now)` and `hour = now.getHours()`.
- Check `notified = item.notifiedStages ?? []`:
  1. **Stage `'evening-before'` (1 Day Before Evening Briefing)**:
     - Condition: `diffDays === 1 && hour >= eveningHour` AND `!notified.includes('evening-before')`.
     - Message: `"🌙 Huhhhh? Tomorrow's quest: ${item.text}~"`
  2. **Stage `'due-day'` (Due Today / Morning Catch-Up Briefing)**:
     - Condition: `diffDays === 0 && hour >= 9` AND `!notified.includes('due-day')`.
     - Message: `"⏰ Today's quest is due: ${item.text}! Yaha~"`
  3. **Stage `'overdue'` (Past Due Nudge)**:
     - Condition: `diffDays < 0` AND `!notified.includes('overdue')`.
     - Message: `"📝 Overdue quest waiting: ${item.text}~"`
- When an alert fires for an item, append its `stage` to `item.notifiedStages` in the returned `ReminderState` so it never fires twice (even across app restarts once saved to `usagi-reminders.json`).
- Also in `reminderStore.ts`: if an item's `dueDate` changes, reset `notifiedStages: []`.

## 3. Review Focus (Top 5 Edge Cases)

1. **Backward-Compatible JSON Deserialization**: Existing `usagi-reminders.json` without `subtasks`, `completedPomodoros`, `estimatedPomodoros`, `notifiedStages`, or `activeFocusQuestId` must deserialize cleanly without throwing or dropping existing quests.
2. **Anti-Spam Deadline Alert Idempotency**: Once `'evening-before'`, `'due-day'`, or `'overdue'` is recorded in `item.notifiedStages`, subsequent 5-second ticks or app restarts must NEVER re-trigger the same stage for that item.
3. **Focus Quest Lifecycle Cleanup**: Completing, deleting, or clearing the currently focused quest must automatically reset `activeFocusQuestId` to `null` so ghost IDs never linger.
4. **Inline Token Order Independence**: Combining `@tomorrow` and `~3p` in any order (e.g. `"Study math ~3p @tomorrow"` or `"@today ~2pom Read paper"`) must strip both tokens cleanly and set both `dueDate` and `estimatedPomodoros`.
5. **UI Subtraction & Layout Safety**: Subtasks remain collapsed behind a compact `[done/total]` pill by default so the Sticky Note stays clean and uncluttered.
