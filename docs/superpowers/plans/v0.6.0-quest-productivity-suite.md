- **Target Branch**: `feat/v0.6.0-quest-productivity-suite`
- **Core Philosophy (Law 5 Subtraction by Default & Karpathy Guidelines)**:
  1. **Remove Clutter**: Delete `SubtaskItem` (`+step` button, sub-quest drawers) and Quest-Linked Pomodoro (`🍅` button on every row, `activeFocusQuestId`, `~Np` tokens, `completedPomodoros`, `estimatedPomodoros`) across `reminderStore.ts`, `main/index.ts`, `preload/index.ts`, `sticky/`, and `dashboard/`. Also remove the redundant "Quests & Focus Targets" card from `src/dashboard/` if it only duplicated the Sticky Note with `+step`/`🍅` bloat (keep Dashboard's clean Calendar/Schedule/Settings layout).
  2. **Honest Date-Only Daily Digest (`src/core/deadlineScheduler.ts`)**:
     - Quests only have `dueDate: YYYY-MM-DD` (no fake hour/minute precision).
     - Instead of per-item spam, `evaluateDeadlineAlerts(state, now, eveningHour = 19)` emits **at most 1 combined summary bubble** per digest window and only when invoked while Usagi is visible (`!usagiHidden` in `src/main/index.ts`):
       - **Morning / First-Open Today Digest (`'due-day'`, `hour >= 8`)**: Collects all uncompleted quests with `diffDays === 0` (due today) or `diffDays < 0` (overdue) that do NOT yet have `'due-day'` in `notifiedStages`. Marks them all with `'due-day'` in `notifiedStages` and emits **one** combined alert:
         - Single task: `"☀️ Today's quest: ${first.text}! Ganbatte~"`
         - Multiple tasks: `"☀️ Today you have ${count} quests: ${names.slice(0, 2).join(', ')}${count > 2 ? '...' : ''}~"`
       - **Cozy Evening Preview (`'evening-before'`, `hour >= eveningHour`, default 19:00)**: If no `'due-day'` alert fired on this tick, collects all uncompleted quests with `diffDays === 1` (due tomorrow) that do NOT yet have `'evening-before'` in `notifiedStages`. Marks them all with `'evening-before'` and emits **one** combined alert:
         - Single task: `"🌙 Tomorrow's quest: ${first.text}~"`
         - Multiple tasks: `"🌙 Tomorrow you have ${count} quests: ${names.slice(0, 2).join(', ')}${count > 2 ? '...' : ''}~"`
  3. **Smart Natural Language Recurring Quests (`"every Tuesday"`, `"every day"`, etc. in `src/core/reminderStore.ts`)**:
     - Extend `ReminderItem` with a lightweight optional recurrence field:
       ```typescript
       export type QuestRecurrence =
         | { type: 'daily' }
         | { type: 'weekdays' }
         | { type: 'weekly'; dayOfWeek: number }; // 0 (Sun) .. 6 (Sat)
       ```
       (`repeat?: QuestRecurrence` on `ReminderItem`).
     - **Natural Phrase Extraction (`extractRecurrenceToken` inside `extractDueDateToken` / `addReminderItem`)**:
       - Detect natural recurring phrases at the end or inline in the quest text (case-insensitive, multilingual-friendly):
         - `"every day"` / `"everyday"` / `"daily"` / `"@daily"` / `"mỗi ngày"` / `"hàng ngày"` -> `repeat: { type: 'daily' }`, sets initial `dueDate` to `today` (if not explicitly set).
         - `"every weekday"` / `"weekdays"` / `"@weekdays"` -> `repeat: { type: 'weekdays' }`, sets initial `dueDate` to today (or next Monday if today is Sat/Sun).
         - `"every <Weekday>"` (e.g., `"go to English class every Tuesday"`, `"every tue"`, `"every monday"`, `"mỗi thứ ba"`, `"mỗi chủ nhật"`) -> strips `"every Tuesday"` cleanly so `cleanText` is `"go to English class"`, sets `repeat: { type: 'weekly', dayOfWeek: 2 }`, and automatically sets `dueDate` to the upcoming occurrence of that weekday (or today if today is that weekday)!
     - **Smart Rollover on Completion (`toggleReminderItem`)**:
       - When a user checks off (`completed: false -> true`) a quest that has `item.repeat`:
         - Keep the celebration spin trigger working!
         - Option A (Clean Rollover): Advance `item.dueDate` to the **next occurrence** after the current `dueDate` (or after `today` if `dueDate` was in the past):
           - `'daily'`: `+1 day`
           - `'weekdays'`: `+1 day` (skipping Sat/Sun to Monday)
           - `'weekly'`: next matching `dayOfWeek` (`+7 days` or next occurrence after today)
         - Reset `completed: false` and `notifiedStages: []` (or record `lastCompletedYMD: todayYMD` on the item so the UI can show a subtle `🔁` badge and trigger celebration!).
         - **Wait — how does `main/index.ts` detect completion celebration?** Let's check `src/main/index.ts` around `ipcMain.on('toggle-reminder')`: it checks `const wasCompleted = reminderState.items.find(i => i.id === id)?.completed; ... const isCompleted = reminderState.items.find(i => i.id === id)?.completed; if (!wasCompleted && isCompleted)`.
         - To keep celebration AND let the user see it checked off today before rolling over (or roll over cleanly):
           - If we mark `completed: true` when clicked, when does it roll over? OR if `toggleReminderItem` rolls a repeating quest directly to its next `dueDate` (`completed: false`, `dueDate: nextDueDate`, `notifiedStages: []`), we can update `main/index.ts` `toggle-reminder` handler so that if `!wasCompleted && (isCompleted || item.dueDate !== prevDueDate)` it STILL triggers the Usagi celebration spin (`celebrate-quest-complete`)! Even better:Usagi celebrates *"Yaha! Quest complete! Next: Tue~"* while the quest smoothly updates its due date pill to next Tuesday (`🔁 Tue, 10/11`)!
     - **Subtle Visual Indicator on Sticky Note (`src/sticky/sticky.ts`)**:
       - No ugly buttons! If `item.repeat` is defined, just prefix the existing `.reminder-due-badge` text with a tiny `↻ ` (e.g., `↻ Tue` or `↻ Tomorrow`), keeping the Sticky Note 100% minimal and polite.
