3. Helper functions in `src/core/i18n.ts`:
   - `isSupportedLocale(val: unknown): val is SupportedLocale`
   - `detectSystemLocale(rawLocale?: string): SupportedLocale` — inspects `rawLocale` or `Intl.DateTimeFormat().resolvedOptions().locale` (e.g., `'vi-VN'` -> `'vi'`, `'de-DE'` -> `'de'`, `'fr-FR'` -> `'fr'`, `'es-ES'` -> `'es'`, `'ja-JP'` -> `'ja'`, `'ko-KR'` -> `'ko'`, `'zh-CN'` -> `'zh'`, fallback `'en'`).
   - `t(locale: SupportedLocale, key: TranslationKey, params?: Record<string, string | number>): string` — looks up key in `TRANSLATIONS[locale]` with fallback to `TRANSLATIONS.en`, and replaces `{param}` placeholders.
   - `getMonthNames(locale: SupportedLocale): string[]` — 12 localized month names.
   - `getShortMonthNames(locale: SupportedLocale): string[]` — 12 short month names for birthday dropdown (`Jan`..`Dec` / `Th1`..`Th12` / etc.).
   - `getWeekdayLabels(locale: SupportedLocale, weekStartsOn: 0 | 1): string[]` — 7 2-letter/short weekday headers for the Calendar grid (`Mo`..`Su` or `Su`..`Sa`).
   - `getScheduleWeekdayPills(locale: SupportedLocale): { day: number; label: string }[]` — 7 weekday pill labels for the Schedule tab (`Mon`..`Sun`, `T2`..`CN`, etc. in `[1, 2, 3, 4, 5, 6, 0]` order).
   - `getLocalizedHolidayTitle(event: { name: string; localName: string; countryCode: string; type: 'public_holiday' | 'birthday' }, locale: SupportedLocale): string` — returns `event.localName` when `event.type === 'public_holiday'` and `locale` matches the holiday's native language (`vi`->`VN`, `de`->`DE`, `fr`->`FR`, `es`->`ES`, `ja`->`JP`, `ko`->`KR`), or `event.name` otherwise.

## Step 2: Expand Multilingual Recurring Quests in `src/core/reminderStore.ts`

1. In `parseRecurringDayOfWeek(token)` and `extractDueDateToken`:
   - Support **Daily** recurring phrases across languages:
     - EN: `@daily`, `every day`, `everyday`, `daily`
     - VI: `mỗi ngày`, `hàng ngày`, `mỗi hôm`
     - DE: `jeden tag`, `täglich`, `taeglich`
     - FR: `tous les jours`, `chaque jour`, `quotidiennement`
     - ES: `todos los días`, `todos los dias`, `cada día`, `cada dia`, `diario`
     - JA: `毎日`, `まいにち`
     - KO: `매일`
     - ZH: `每天`, `每日`
   - Support **Weekdays** recurring phrases across languages:
     - EN: `@weekdays`, `@weekday`, `every weekday`, `weekdays`
     - VI: `mỗi ngày trong tuần`, `các ngày trong tuần`
     - DE: `jeden werktag`, `werktags`, `wochentags`
     - FR: `tous les jours ouvrés`, `en semaine`
     - ES: `entre semana`, `días laborables`, `dias laborables`
     - JA: `平日`, `毎週平日`
     - KO: `평일마다`, `매주 평일`
     - ZH: `每个工作日`, `每個工作日`, `工作日`
   - Support **Weekly (Day of Week)** recurring phrases across languages:
     - EN: `every (sunday|sun|monday|mon|tuesday|tue|wednesday|wed|thursday|thu|friday|fri|saturday|sat)`
     - VI: `(mỗi|hàng tuần vào) (thứ [2-7]|thứ hai|thứ ba|thứ tư|thứ năm|thứ sáu|thứ bảy|chủ nhật|cn)`
     - DE: `jeden (montag|dienstag|mittwoch|donnerstag|freitag|samstag|sonntag)`
     - FR: `(tous les|chaque) (lundi|mardi|mercredi|jeudi|vendredi|samedi|dimanche)s?`
     - ES: `(todos los|cada) (lunes|martes|miércoles|miercoles|jueves|viernes|sábados|sabados|sábado|sabado|domingos|domingo)`
     - JA: `毎週(月|火|水|木|金|土|日)曜(?:日)?`
     - KO: `매주\s*(월|화|수|목|금|토|일)요일`
     - ZH: `(?:每周|每週|每星期|每个星期|每個星期)(一|二|三|四|五|六|日|天)`
2. Also allow `formatReminderDueBadge(dueDateStr, todayYMD, format, locale: SupportedLocale = 'en')` and `getUpcomingCountdownItems(..., locale: SupportedLocale = 'en')` and `evaluateDeadlineAlerts(state, now, eveningHour, locale: SupportedLocale = 'en')` to format badges/messages in the active `locale` while defaulting to `'en'` so all existing tests remain 100% green.

## Step 3: Persist `locale` in `UserSettings` (`src/core/settingsStore.ts`) & Wire IPC (`src/preload/index.ts`, `src/main/index.ts`)

1. In `src/core/settingsStore.ts`:
   - Add `locale?: SupportedLocale` to `UserSettings` (defaults to `detectSystemLocale()`).
   - Parse and validate `locale` in `parseUserSettingsJson` using `isSupportedLocale`.
2. In `src/preload/index.ts`:
   - Add `setLocale: (locale: SupportedLocale) => void` and `onLocaleChanged: (callback: (locale: SupportedLocale) => void) => () => void` to `UsagiAPI`.
3. In `src/main/index.ts`:
   - Track `currentLocale: SupportedLocale = detectSystemLocale()`.
   - Load/save `locale` in `loadSettingsFromDisk()` / `saveSettingsToDisk()`.
   - Send `win.webContents.send('locale-changed', currentLocale)` in `sendFullStateToWindow(win)` and `stickyWindow.webContents.on('did-finish-load')`.
   - Handle `ipcMain.on('set-locale', (_e, nextLocale: SupportedLocale) => ...)` to update `currentLocale`, save to disk, and `broadcastToAllWindows('locale-changed', currentLocale)`.
   - Use `t(currentLocale, ...)` for birthday greeting, wellness water reminder, welcome back message, and pass `currentLocale` into `evaluateDeadlineAlerts(reminderState, new Date(), 19, currentLocale)`.

## Step 4: Wire Language Selector & Live Re-Render in Dashboard, Sticky Note, and Tray

1. **Dashboard (`src/dashboard/index.html` & `src/dashboard/dashboard.ts`)**:
   - Add a **Language** row at the top of the **Buddy Profile & Holiday Region** card with `<select id="buddy-language-select" class="config-select">` containing the 8 `SUPPORTED_LOCALES`.
   - Add `renderLocaleUI(locale: SupportedLocale)` in `src/dashboard/dashboard.ts` that updates all Dashboard section titles, tab buttons, timer labels/buttons, wardrobe labels, mode labels/buttons, and settings labels, plus re-runs `updatePomodoroUI`, `renderReminderConfigUI`, `updateStationaryUI`, `updatePlayModeUI`, `updateGhostModeUI`, `updateFixedAppearanceUI`, `updateUsagiHiddenUI`.
   - Listen to `window.usagiAPI.onLocaleChanged((locale) => renderLocaleUI(locale))` and wire `buddyLanguageSelect.addEventListener('change', ...)`.
2. **Sticky Note (`src/sticky/ sticky.ts`)**:
   - Track `currentLocale: SupportedLocale = 'en'`.
   - Listen to `window.usagiAPI.onLocaleChanged((locale) => { currentLocale = locale; renderStaticLocaleText(); render(currentState); })`.
   - Localize header title (`sticky.title`), tab buttons (`Quests`, `Calendar`, `Schedule`), input placeholders, footer (`completed`, `Clear Done`), calendar month title, weekday headers, upcoming list, localized holiday names (`getLocalizedHolidayTitle`), and schedule view texts.
3. **Taskbar Tray (`src/tray/tray.ts`)**:
   - Track `currentLocale: SupportedLocale = 'en'`.
   - Listen to `window.usagiAPI.onLocaleChanged((locale) => { currentLocale = locale; renderTrayLocale(); })` to localize Tray status pill, Start/Pause/Resume/Reset buttons, Dashboard button, Sticky Quests toggle, Hide/Show Usagi toggle, Drop Snack button, and Quit button.
